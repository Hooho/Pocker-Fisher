# 摸鱼的时候玩德州吧！

随时打开！随时关闭！随时退出！
- **完全离线**：不联网、不注册，断网也能玩。
- **随时退出**：关闭页面或应用，进度实时保存在本地。
- **存档带走**：导出 JSON 存档或存档码，在其他设备导入后继续。
- **电脑对手**：和 63 位性格各异的角色对局，选择适合自己的难度

## 两种玩法

### 单次赛

选择 2、4、6 或 8 人，打一场独立牌局

### 冠军之路

64 位选手分桌出发，经过首轮、次轮、半决赛和总决赛，逐轮晋级，直到决出冠军

## 不用担心进度

牌局、冠军赛和战绩会自动保存。

想换设备时，在“更多”中导出存档；打开新设备上的游戏后，选择“导入存档”即可继续。

祝你摸鱼愉快！！
