# RIVER CLUB · 摸鱼德州

一款和电脑选手对战的本地德州扑克游戏。你可以打一场独立牌局，也可以参加从 64 人一路打到冠军的冠军之路。

## 先记住这三点

- **完全离线**：游戏本体不联网、不需要账号或服务器，断网也可以完整游玩。
- **随时退出**：可以随时退出牌桌、关闭页面或关闭应用，当前进度会实时保存在本地。
- **可以换设备**：在“更多”中导出存档文件或存档码，把它传到其他设备后，通过“导入存档”继续游戏。

## 游戏目标

这是无限注德州扑克：每位选手拿两张底牌，桌面最多发出五张公共牌。用自己的两张底牌和公共牌组成最强的五张牌，赢下底池；筹码归零即被淘汰。

## 选择比赛模式

### 单次赛

- 2、4、6 或 8 人同桌，包含你在内。
- 每位选手以 10,000 筹码开始。
- 没有晋级流程，直到只剩一名选手；最终筹码排名会记录在单次赛结算中。
- 可选择电脑水平，以及每 5、10 或 20 手上涨一次盲注的节奏。

### 冠军之路

- 64 名选手分桌比赛，依次经过首轮、次轮、半决赛和总决赛。
- 首轮、次轮、半决赛均为每桌 8 进 4，最后 8 人进入总决赛。
- 总决赛按 8、6、4、2、1 人逐步淘汰，最后留下的选手成为冠军。
- 入座前可以选择晋级时将筹码重置为 10,000，或保留上一轮筹码。
- 其他牌桌会在后台自动模拟。你若被淘汰，赛事仍会继续模拟到冠军产生。

## 一手牌怎么玩

1. 每手牌开始时，系统轮换庄家，并收取小盲注和大盲注。两人单挑时，庄家同时承担小盲注。
2. 每位仍在牌局中的选手获得两张底牌。
3. 经过下注后，依次发出翻牌三张、转牌一张和河牌一张公共牌；每次发牌后都会有一轮下注。
4. 轮到你时，在底部操作区选择行动。所有下注均为无限注规则，可以投入当前剩余的全部筹码。
5. 所有人完成下注、弃牌或全下后进行比牌。系统自动从七张可用牌中选出最强的五张牌，胜者获得底池。
6. 本手结束后点击“下一手”。筹码归零的选手会被淘汰，直到比赛结束或进入下一轮。

## 操作说明

- **弃牌**：放弃本手，不再争夺底池。
- **过牌**：当前无需跟注时不投入筹码，继续留在牌局中。
- **跟注**：补足当前最高下注。
- **加注**：把本轮自己的总下注提高到指定金额；可以直接输入金额、拖动滑块，或使用四分之一池、半池、满池等快捷金额。
- **全下**：投入剩余全部筹码。确认后不能撤回。
- 快捷键：`F` 弃牌、`C` 过牌/跟注、`R` 加注。

牌桌顶部可以暂停或继续牌局，也可以退出牌桌。退出牌桌、关闭页面或关闭应用后，当前牌局、冠军赛进度和历史记录都会实时保存到本地，不需要专门点击保存。

需要换设备时，在原设备打开“更多”→“导出存档”，下载 JSON 存档文件，或复制存档码；在新设备打开游戏后选择“更多”→“导入存档”，上传文件或粘贴存档码即可恢复进度。

## 牌型大小

从大到小依次为：

1. 皇家同花顺
2. 同花顺
3. 四条
4. 葫芦
5. 同花
6. 顺子
7. 三条
8. 两对
9. 一对
10. 高牌

花色不分大小。牌型相同时，会继续比较组成牌型的点数和踢脚牌；完全相同则平分底池。多人下注时，系统会自动计算主池和边池，并分别派奖。

## 冠军积分

- 单次赛只有最终赢家获得积分：2、4、6、8 人桌的基础分分别为 1、2、3、4 分；电脑水平越高，积分倍率越高。
- 冠军之路前八名获得名次分：冠军 20 分、亚军 15 分、季军 12 分，第 4 至第 8 名依次为 11、10、9、8、7 分，再按电脑水平倍率计算。
- 冠军之路中每赢下一手牌，额外获得 0.1 分；这部分不受难度倍率影响。
- 总积分相同时，依次比较赢手总数、历史最佳名次和参赛场次。

## 提示

牌桌上的对手头像可以点击查看人物档案。设置中的电脑水平会影响对手策略，涨盲节奏会影响牌局速度；想专注练习时，可以先使用较低难度或较慢的涨盲节奏。
